# Test prompts

These four WAV files are temporary English prompts for the SM-T585 live menu test:

- `main-menu.wav`: main menu for keys 1, 2, and 0
- `sales-unavailable.wav`: terminal sales response
- `support-unavailable.wav`: terminal support response
- `operator-unavailable.wav`: terminal operator response

They are 48 kHz, stereo, signed 16-bit PCM and are intentionally shorter than the guardian's
15-second prompt-phase deadline.

The recordings were synthesized with a local macOS system voice. They are test fixtures, not
publication-cleared project assets and are not granted under IVRdroid's AGPL license. Replace
them with recordings whose redistribution terms are known before publishing a release.
